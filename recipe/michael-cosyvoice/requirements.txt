# - torch and torchaudio are NOT listed here: the Dockerfile installs the
#   2.7.0 pair from PyTorch's cu128 index. Upstream's torch==2.3.1 exists
#   only for CUDA 12.1 and cannot run on RTX 50-series (Blackwell, sm_120)
#   GPUs.
# - Dropped: deepspeed and tensorrt-cu12* (Linux-only acceleration),
#   onnxruntime-gpu (the flow estimator and speech tokenizer ONNX files
#   run on the CPU build; the LLM and vocoder stay on CUDA), the web/demo
#   stack (fastapi, fastapi-cli, uvicorn, gradio, grpcio, grpcio-tools,
#   tensorboard), and wetext (its normalizer data downloads from ModelScope
#   on every model load, which breaks self-contained offline runs; the
#   recipe reads text as written — the prep stage owns text normalization).
# - openai-whisper 20231117 -> 20250625: the older release needs
#   pkg_resources at build time and fails to build. CosyVoice only uses its
#   mel-spectrogram frontend.
# - Kept: gdown, wget, pyarrow — upstream imports them at runtime.
#
